# AWS Research

## 1. Brief Overview
Amazon Web Services(AWS) provides a broad set of global cloud-based products including compute, storage, databases, analytics, networking, mobile, developer tools, management tools, IoT, security, and enterprise applications, like on-demand, available in seconds, with pay-as-you-go pricing.

## 2. Global Infrastructure
The AWS global infrastructure said that this is the most secure, reliable, and extensive cloud, providing diverse infrastructure solutions for running our applications anywhere. They have three Availability Zones (AZs) per Region and optimized data centers, and also AWS global infrastructure maximizes resilience, performance, and innovation. They also have nearly 20 million kilometers of fiber optic cabling, and their AWS’s global network backbone enables faster data transfer, reduced latency, and enhanced application performance.

## 3. Cloud Management Console
The AWS Management Console is a web-based application that provides a centralized access to all individual AWS service consoles. Where you can use Unified Navigation in the AWS Management Console to search for services, view notifications, access AWS CloudShell, access account and billing information, and customize your general console settings.

## 4. Four Core Services
### Amazon CloudFront
-content delivery network
### AWS Amplify
-open-source client libraries to build cloud powered mobile and web apps
### Amazon EventBridge
-integration with AWS & 3rd party services through events
### Amazon Simple Storage Service
-file storage

## 5. Three Advantages
### Trade fixed expense for variable expense 
-Instead we have to invest heavily in data centers and servers before we know how we’re going to use them, we can pay only when we consume computing resources, and pay only for how much we consume.

### Benefit from massive economies of scale
-By using cloud computing, we can achieve a lower variable cost than we can get on our own.

### Stop guessing capacity
-this will eliminate guessing on our infrastructure capacity needs. 

## 6. Typical Enterprise Use Cases
AWS can be used by enterprises for:

- Hosting websites and web applications
- Storing and backing up business data
- Running databases
- Developing and deploying applications
- Building scalable business systems
