# Laboratory 03 - Multi-Cloud Explorer

This laboratory activity explores and compares Amazon Web Services (AWS), Microsoft Azure, and Google Cloud Platform (GCP).

## Linux Server Cloud Migration

If this Linux server were migrated to the cloud, it could be hosted using virtual machine services from the three major cloud providers.

### AWS

Amazon EC2 could be used to host the Linux server as a virtual machine.

### Microsoft Azure

Azure Virtual Machines could be used to run the Linux server in the Azure cloud.

### Google Cloud

Google Compute Engine could be used to host the Linux server as a virtual machine.
