# Mission 3 Reflection

Completing Mission 3 helped me understand the differences between AWS, Microsoft Azure, and Google Cloud Platform. Before doing this activity, I mostly knew these platforms as cloud service providers, but researching their services helped me understand that each provider has different strengths. The cloud platform that impressed me the most was GCP because it has a allowance for students and that's a big help to us.

One similarity among AWS, Azure, and Google Cloud is that they all provide important cloud services such as computing, storage, networking, databases, and security. However, they differ in the way they organize their services and the areas where they are particularly strong. This made me realize that choosing a cloud provider should not be based only on popularity.

Business requirements have an important effect on cloud platform selection. For example, Azure can be a good choice for an organization that already depends heavily on Microsoft technologies. On the other hand, a company focused on AI and Kubernetes may consider Google Cloud, while AWS can be useful for organizations that need a broad range of cloud services.

Acting as a Cloud Solutions Consultant taught me that technical decisions should be connected to the actual needs of a client. I learned that the best cloud platform depends on factors such as budget, existing technology, workload, scalability, and business goals.

This activity also improved my GitHub Cloud Computing Portfolio because I added organized research, comparison tables, recommendations, screenshots, and Linux investigation results. Overall, the activity helped me become more familiar with cloud services and improved my understanding of how cloud technologies can be matched to real business situations.
